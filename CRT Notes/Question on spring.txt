What exactly happens when spring starts ?

Spring Boot startup sequence:

1. SpringApplication.run()
2. Creates ApplicationContext
3. Reads configuration
4. Performs component scanning
5. Creates Bean Definitions
6. Resolves dependencies
7. Applies BeanPostProcessors
8. Initializes singleton beans
9. Starts embedded server (Tomcat/Netty)
